# Dashboard Report

# Objective 
Create a visual summary of business performance using charts and KPI metrics.

# Dashboard Components 
- Total Sales
- Total Orders
- Average Sales
- Category-wise Sales
- Monthly Sales Trend
- Sales Distribution

# Key Insights
- Revenue is concentrated in a few categories.
- Sales fluctuate across months.
- Most orders fall within a moderate sales range.

# Conclusion
The dashboard provides a clear and interactive view of business performance, helping stakeholders make faster and more informed decisions.
